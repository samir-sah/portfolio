# Samir Sah - Personal Portfolio

This is the personal portfolio website for **Samir Sah**, a Software Engineer specializing in backend engineering, distributed systems, and full-stack development. 

The portfolio showcases experience, projects, skills, and provides a way to get in touch.

## 🚀 Tech Stack

This project is built using modern web technologies:

- **Framework**: [Next.js](https://nextjs.org/) (React 19)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) & [Lenis](https://lenis.studiofreight.com/) (Smooth Scrolling)
- **UI Components**: Custom components, [Shadcn UI](https://ui.shadcn.com/), and [Lucide Icons](https://lucide.dev/)
- **Analytics**: [Vercel Analytics](https://vercel.com/analytics)

## ✨ Features

- **About & Experience**: Details on professional experience and core interests.
- **Projects Showcase**: Highlights of significant projects (e.g., Business Admin Dashboard, API Sentinel).
- **Tech Stack & Skills**: Comprehensive list of languages, frontend/backend technologies, databases, and DevOps tools.
- **Contact Section**: Integrated contact form and links to professional profiles (GitHub, LinkedIn, LeetCode).
- **Responsive & Accessible**: Designed to work flawlessly across devices and screen sizes.

## 🛠️ Getting Started

To run this project locally, follow these steps:

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine. The project uses `pnpm` for package management (though you can use npm or yarn).

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/samir-sah/portfolio.git
   cd portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   pnpm install
   # or
   yarn install
   ```

3. Run the development server:
   ```bash
   npm run dev
   # or
   pnpm dev
   # or
   yarn dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.
